Privacy & data handling

  • Extract — facets are parsed from the page DOM of the AI tab you click on. No network request is made.
  • Compress — the passport is rendered into the mode you pick, locally.
  • Store — saved in chrome.storage.local on this device only. Never transmitted.
  • Copy / Inject — pasted into the active AI tab's composer only when you click. You always edit before sending.

0 outbound requests. Verify in DevTools → Network. Disabling storage stops new captures from being saved; existing data is preserved until you erase it.
